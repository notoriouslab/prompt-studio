線上版已涵蓋兩條日常路徑：複製貼上（⧉ ChatGPT／⧉ Gemini 一鍵按鈕）與內建 AI 展開（自備免費 Gemini API key 或任何 OpenAI 相容端點）。附帶的 launcher（macOS PromptStudio.command、Windows PromptStudio.bat） 只有第三條路才需要：接上你本機的 ollama，整條流程都在自己機器上跑。

看看這條產線的示範片

一部偽紀錄片（Found Footage）風格的恐怖驚悚短片。這是刻意保留的粗剪： 所有提示詞都是 Video Prompt Studio 樣板直出、未經任何調整，在 VideoExpress 一次生成、沒有重抽，只有音樂是後製配上的。請把它當成這條產線的「地板」而 不是「天花板」：修訂輪迭代與人工把關介入之前，一次直出就是這個樣子。

為什麼做這個

訂製型 AI 助手一個接一個收攤，最近的是 Google 的 Gemini Gems： 應用內通知指向 2026 年 10 月停用。你在任何廠商的助手裡精心累積的規則書， 都會跟著一起消失。

Video Prompt Studio 押相反的注：你的提示詞產線不該住在任何一家的 助手裡。它產出的是一份自足的完整規則書提示詞，貼進 ChatGPT、Claude、 Gemini 或未來任何新工具都能直接用。想一鍵完成？在內建的 AI 展開面板貼一組 免費 Gemini API key（或任何 OpenAI 相容端點）即可；若你用 ollama 跑本地模型， 從點子到分鏡表整條產線都在自己的硬體上完成。

它做什麼

選一種模式（多鏡分鏡、單鏡頭、首尾幀、談話頭像、直式短影音），設好時長 與畫幅，描述你的點子。工具會編譯出一份製作規格：硬性限制、平台校準 （以 VideoExpress.ai 實拍驗證）、 寫實感規則、防字幕燒錄規則，以及從真實生成失敗中萃取的「可畫性」規則。 AI 助手照著這份規格展開成可直接貼用的提示詞。

內建產線：概念 → 劇本 → 分鏡提示詞

AI 展開面板讓產線三段不出頁面就能完成——打自己的免費 Gemini key、任何 OpenAI 相容端點，或本機 ollama：

  1. 概念變劇本
    打一句故事概念，內建編劇規範（改編自 MIT 授權的 AI-drama-pound）直接 產出可拍攝的完整劇本：場次標頭、埋好的反轉線索、不寫解說型對白。
  2. 劇本變分鏡提示詞
    過目劇本後一鍵轉入。台詞逐字保留、場景拆成帶時間軸的分鏡、 角色自動映射為編號演員代稱並凍結外觀描述。
  3. 修訂到滿意為止
    打一句批評（例如「shot 5 缺行進中的環境流動感」），模型帶著完整規則書 重出修訂版，迭代再多輪也不會漂移出平台規則。

核心特色

  • 天生可攜：產出就是純文字提示詞，今天的任何聊天 AI 能用，明年出的新工具也能用
  • 內建 AI 展開，自備 key 或自備硬體：貼免費 Gemini API key 或任何 OpenAI 相容端點即可頁內展開（key 只存瀏覽器、呼叫瀏覽器直連）， 也可全程打自己的 ollama；輸出串流渲染成可讀版面
  • 實拍驗證的平台規則：VideoExpress 真實跑片校準， 演員代稱抗跨鏡漂移、對嘴台詞長度上限、防字幕燒錄措辭、逐鏡密度預算
  • 可畫性規則：禁鏡中反射、禁畫中畫、文生圖只寫靜態 姿態而動作留給圖生影片，全部萃取自真實生成失敗的提示詞
  • 五種模式：多鏡分鏡、單鏡頭、首尾幀、談話頭像、 直式短影音，另有精簡、完整、工單三種輸出格式
  • 給瀏覽器代理的工單輸出：機器可執行的工作單， AI 代理（如 Claude in Chrome）能照單全程操作影片平台
  • 單檔、本機優先：模板與版本存在瀏覽器的 localStorage， 隨時可用 JSON 匯出匯入

常見問題

需要帳號或 API 金鑰嗎？

永遠不需要帳號。複製貼上路徑完全不用金鑰：⧉ 按鈕會自動複製提示詞並開啟 ChatGPT／Gemini。想一鍵頁內展開，再自備免費 Gemini API key（或 OpenAI 相容端點、本機 ollama）即可。

免費嗎？

完全免費且開放原始碼（MIT 授權）。它是為了自己的影片產線做的工具， 沒有商業模式、不用註冊、沒有遙測。

我的資料存在哪？

存在你裝置上的瀏覽器 localStorage，API key 也是。工具本身除了本頁的 GitHub 版本查詢外沒有任何網路請求；AI 展開由瀏覽器直連你選的 provider， 本地模型模式只跟 localhost 溝通。沒有任何後端。

支援哪些影片生成工具？

內建校準以 VideoExpress.ai 實拍驗證。不過產出的規格是純文字， 角色設定書與帶時間軸的成對提示詞這套結構搬去其他生成工具也能用， 只是少了平台專屬的調校。

本地（ollama）路徑需要什麼？

裝好 ollama 與一個夠力的模型（我們以 36 GB 的 Mac 跑 Qwen 27B 測試），並從 localhost 開啟頁面，附帶的 PromptStudio.command 與 PromptStudio.bat 雙擊即可。連不到 ollama 時該選項只是反灰，Gemini key 與複製貼上兩條路 完全不受影響。

有英文版嗎？

有，工具本身中英雙語（右上角切換），本頁另有 English 版。
